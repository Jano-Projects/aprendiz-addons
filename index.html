Instalar um addon

  1. Baixe o arquivo .aprendiz. Comece pelos essenciais, na ordem indicada.
  2. No Aprendiz, abra Addons no menu lateral e clique em Importar addon.
  3. Confira o resumo (origem, o que ele traz, dependências) e clique em Instalar.
  4. Se quiser, marque Usar como padrão para ativar a busca e a resposta recomendadas.
  • Addons contêm só dados (texto), nunca programas. O app valida cada arquivo ao importar.
  • O que você ensina sempre vence os addons, inclusive sinônimos e abreviações.
  • Se dois addons explicam o mesmo termo de jeitos diferentes, o Aprendiz 1.0 pergunta a você em vez de escolher sozinho.
  • Desativar um addon só o esconde das respostas; nada é apagado.

Criar um addon

Esta loja distribui só os addons oficiais da Jano Projects. Qualquer pessoa pode criar addons para uso próprio ou compartilhar o arquivo diretamente, a partir de um texto simples de perguntas e respostas. O próprio app também exporta o que você ensinou.
