F: tipos
A: tipos de dados python, int, float, str, bool, type

R: Os tipos básicos:
- `int`: inteiros de **qualquer tamanho** (`2 ** 100` funciona);
- `float`: reais (`3.14`, `1e-3`);

F: f-string
A: f-string, formatar texto, variável dentro do texto, interpolação
Q: porque | o f antes das aspas deixa pôr variáveis entre chaves dentro do texto | -> strings

P: o que é f string
P: f string
P: formatar string python
R: A **f-string** (o `f` antes das aspas) coloca valores e expressões dentro do texto, entre `{}`:
```python
nome, preco, qtd = "Café", 12.5, 3
print(f"{nome}: {qtd} x R$ {preco:.2f} = R$ {qtd * preco:.2f}")
# Café: 3 x R$ 12.50 = R$ 37.50

f"{1234567.891:,.2f}"   # '1,234,567.89'
f"{0.256:.1%}"          # '25.6%'
f"{'esq':<10}|"         # alinhado à esquerda em 10 colunas
f"{42:05d}"             # '00042'
f"{x=}"                 # 'x=10': ótimo para depurar
```
Para o formato brasileiro (1.234,56), troque os separadores: `f"{v:,.2f}".replace(",", "X").replace(".", ",").replace("X", ".")`.

F: match
A: match case, switch em python, casamento de padrões

P: como usar match case em python
R: O `match` (Python 3.10+) compara um valor com padrões:
```python
comando = input("> ").split()
match comando:
    case ["sair"]:
        print("Tchau")
    case ["ola", nome]:
        print(f"Olá, {nome}!")
    case ["somar", *numeros]:
        print(sum(int(n) for n in numeros))
    case _:
        print("Comando desconhecido")
```
Ele vai além do `switch` de outras linguagens: desmonta listas, tuplas e dicionários e captura partes em variáveis (`nome`, `*numeros`). O `_` pega qualquer coisa.

R: O `for` do Python percorre **qualquer coleção**, item por item:
```python
for fruta in ["maçã", "pera", "uva"]:
    print(fruta)

for letra in "abc":
    print(letra)

for i in range(5):          # 0, 1, 2, 3, 4
    print(i)
for i in range(1, 11, 2):   # 1, 3, 5, 7, 9 (início, fim, passo)
    print(i)

for i, fruta in enumerate(["maçã", "pera"], start=1):   # posição e item

    print(nome, nota)
```
Evite `for i in range(len(lista))` só para pegar `lista[i]`: use o item direto ou `enumerate`.

```python
notas = [7, 8.5, 6]

notas.insert(0, 10)      # na posição 0
```

F: dicionario
A: dicionário python, dict, chave e valor, mapa

P: como usar dicionários em python
R: O **dicionário** guarda pares **chave → valor** e acha uma chave muito rápido:
```python
aluno = {"nome": "Ana", "idade": 20}
aluno["curso"] = "ADS"            # adiciona
```

F: parametro-padrao
A: parâmetro com valor padrão, argumento opcional, parâmetro nomeado
Q: porque | o parâmetro pode ter um valor usado quando não é passado nada | -> prog-logica:parametro-argumento

P: o que são parâmetros com valor padrão em python
P: o que é argumento nomeado em python
P: o que é args e kwargs
R: ```python
def saudar(nome, saudacao="Olá", pontuacao="!"):
    return f"{saudacao}, {nome}{pontuacao}"

saudar("Ana")                        # 'Olá, Ana!'
saudar("Ana", pontuacao=".")         # argumento nomeado: 'Olá, Ana.'

def somar(*numeros):                 # *args: quantos quiser, numa tupla
    return sum(numeros)
somar(1, 2, 3)

def ficha(**dados):                  # **kwargs: nomeados, num dicionário
    for k, v in dados.items():
        print(k, v)
ficha(nome="Ana", idade=30)
```
Armadilha clássica: **nunca** use lista ou dicionário como valor padrão (`def f(itens=[])`): a mesma lista é reaproveitada entre as chamadas. Use `def f(itens=None):` e, dentro, `itens = itens or []`.

F: escopo
A: escopo python, global, local, nonlocal
Q: porque | a variável criada dentro da função só existe nela | -> prog-logica:escopo
P: o que é escopo em python
P: o que é global em python
R: Variáveis criadas dentro de uma função são **locais**. A função **lê** variáveis de fora, mas, ao **atribuir**, cria uma local nova:
```python
contador = 0

def incrementar():
    global contador     # sem isto, daria UnboundLocalError
    contador += 1
```
Evite `global`: prefira receber por parâmetro e devolver com `return`:
```python
def incrementar(contador):
    return contador + 1
contador = incrementar(contador)
```
A ordem de busca de um nome é **LEGB**: Local, Enclosing (função de fora), Global, Built-in.

F: main
A: if __name__ == __main__, rodar só quando executado, ponto de entrada
Q: porque | o código dentro dele só roda quando o arquivo é executado, e não quando é importado | -> import
P: o que é if __name__ == "__main__"
P: para que serve __main__ em python
R: Cada módulo tem a variável `__name__`. Ela vale `"__main__"` quando o arquivo é **executado direto**, e o nome do módulo quando é **importado**. Assim, o mesmo arquivo serve de programa e de biblioteca:
```python
def somar(a, b):
    return a + b

if __name__ == "__main__":
    print(somar(2, 3))     # só roda com "python arquivo.py", não no import
```
O `iniciar.py` do Aprendiz usa esse padrão para chamar a função `main()`.

F: excecoes
A: tratar erros, try except, exceção, programa não fechar com erro, programa fecha sozinho, programa fechou com erro, evitar que o programa feche
Q: porque | sem tratamento, o erro interrompe o programa; o except decide o que fazer em vez de fechar | -> prog-logica:tipos-erro
P: como tratar erros em python
P: como usar try except em python
P: quais as exceções mais comuns em python
P: como tratar exceção em python
P: exceção em python
P: try except
R: ```python
try:
    numero = int(input("Número: "))
    print(10 / numero)
except ValueError:
    print("Isso não é um número.")
except ZeroDivisionError:
    print("Não dá para dividir por zero.")
else:
    print("Deu certo")            # só se não houve erro
finally:
    print("Sempre roda")          # com ou sem erro
```
As exceções mais comuns:
- `ValueError`: valor inválido (`int("abc")`);
- `TypeError`: tipo errado (`"a" + 1`);
- `KeyError`: chave inexistente num dicionário;
- `IndexError`: índice fora da lista;
- `AttributeError`: atributo ou método que não existe;
- `FileNotFoundError`: arquivo inexistente;
- `ZeroDivisionError`, `NameError` (variável não definida).
Capture só os erros que sabe tratar; um `except:` sozinho esconde bugs. Para lançar: `raise ValueError("idade negativa")`.

P: abrir arquivo em python

P: como salvar texto em arquivo no python
R: Use sempre `with`: ele fecha o arquivo sozinho, mesmo se der erro.
```python
# escrever ("w" apaga o conteúdo; "a" acrescenta no fim)
with open("notas.txt", "w", encoding="utf-8") as f:
    f.write("Ana;8.5\n")
    f.write("Bia;9.0\n")

# ler linha por linha
with open("notas.txt", encoding="utf-8") as f:
    for linha in f:
        nome, nota = linha.strip().split(";")

# ler tudo de uma vez
with open("notas.txt", encoding="utf-8") as f:

```

```python
from pathlib import Path
```

F: programa-completo
A: exemplo de programa completo, programa de exemplo
Q: exemplo-de | junta entrada, decisões, laços e funções num programa só | -> funcao
P: exemplo de programa completo em python
P: jogo de adivinhação em python
R: Um jogo de adivinhar o número, com o básico todo:
```python
import random

def jogar():
    segredo = random.randint(1, 100)
    tentativas = 0
    print("Pensei num número de 1 a 100.")
    while True:
        try:
            chute = int(input("Seu chute: "))
        except ValueError:
            print("Digite um número inteiro.")
            continue
        tentativas += 1
        if chute < segredo:
            print("É maior.")
        elif chute > segredo:
            print("É menor.")
        else:
            print(f"Acertou em {tentativas} tentativas!")
            break

if __name__ == "__main__":
    jogar()
```
Exercício: limitar a 7 tentativas e guardar o recorde num arquivo.
