# Atalhos de teclado do Windows 10 e 11. "Win" é a tecla com o logotipo do Windows.
# Várias linhas P: no mesmo bloco = jeitos diferentes de perguntar a mesma coisa.

P: como abrir o explorador de arquivos no windows
P: atalho para abrir meus arquivos
P: como abrir o windows explorer
P: o que faz win e
R: Win+E abre o Explorador de Arquivos.

P: como mostrar a área de trabalho no windows
P: como minimizar todas as janelas
P: atalho para ir para o desktop
P: o que faz win d
R: Win+D mostra a área de trabalho. Aperte de novo para voltar às janelas.

P: como bloquear o computador no windows
P: como travar a tela do computador
P: atalho para bloquear o pc
P: o que faz win l
R: Win+L bloqueia o computador na hora.

P: como tirar um print de uma parte da tela no windows
P: como fazer captura de tela no windows
P: como tirar print no windows
P: atalho da ferramenta de captura
P: o que faz win shift s
R: Win+Shift+S abre a Ferramenta de Captura para escolher a área. A imagem vai para a área de transferência. A tecla PrtSc (Print Screen) captura a tela inteira.

P: como tirar print da tela inteira e salvar em arquivo no windows
P: onde ficam salvos os prints do windows
R: Win+PrtSc captura a tela inteira e salva o arquivo em Imagens > Capturas de Tela.

P: como ver o histórico da área de transferência no windows
P: como ver o que eu copiei antes
P: como recuperar um texto copiado antes
P: o que faz win v
R: Win+V. Na primeira vez, o Windows pede para ativar o recurso.

P: como alternar entre janelas no windows
P: como trocar de janela pelo teclado
P: como mudar de programa aberto
P: o que faz alt tab
R: Alt+Tab alterna entre as janelas. Win+Tab abre a Visão de Tarefas, com todas as janelas e áreas de trabalho.

P: como abrir o gerenciador de tarefas no windows
P: como fechar um programa travado no windows
P: o computador travou o que fazer
P: atalho do gerenciador de tarefas
R: Ctrl+Shift+Esc abre direto o Gerenciador de Tarefas. Lá, selecione o programa e clique em Finalizar tarefa.

P: como abrir as configurações do windows
P: atalho para as configurações do pc
P: o que faz win i
R: Win+I abre as Configurações.

P: como abrir a janela executar no windows
P: o que faz win r
R: Win+R abre a janela Executar.

P: como encaixar uma janela na metade da tela no windows
P: como dividir a tela em duas janelas
P: como colocar duas janelas lado a lado
P: como maximizar uma janela pelo teclado
R: Win+seta para a esquerda ou para a direita encaixa a janela na metade da tela. Win+seta para cima maximiza.

P: como criar uma nova área de trabalho virtual no windows
P: como usar várias áreas de trabalho no windows
R: Win+Ctrl+D cria uma área de trabalho virtual. Para alternar entre elas: Win+Ctrl+seta para a esquerda ou para a direita. Win+Ctrl+F4 fecha a atual.

P: como inserir emojis no windows
P: como colocar emoji no computador
P: atalho do painel de emojis
R: Win+. (tecla Windows e ponto) abre o painel de emojis.

P: como renomear um arquivo rapidamente no windows
P: atalho para renomear arquivo
P: o que faz f2
R: Selecione o arquivo e aperte F2.

P: como desfazer a última ação no windows
P: como voltar o que eu apaguei sem querer
P: o que faz ctrl z
R: Ctrl+Z desfaz. Para refazer: Ctrl+Y.

P: como copiar e colar no windows
P: atalho de copiar e colar
P: o que faz ctrl c e ctrl v
R: Ctrl+C copia, Ctrl+X recorta e Ctrl+V cola.

P: como selecionar tudo no windows
P: o que faz ctrl a
R: Ctrl+A seleciona tudo (textos, arquivos de uma pasta…).

P: como procurar uma palavra na página ou no documento
P: como pesquisar dentro de um texto
P: o que faz ctrl f
R: Ctrl+F abre a busca em quase todos os programas e navegadores.

P: como salvar um arquivo pelo teclado
P: o que faz ctrl s
R: Ctrl+S salva o arquivo aberto.

P: como imprimir pelo teclado
P: o que faz ctrl p
R: Ctrl+P abre a janela de impressão.

P: como reabrir uma aba fechada do navegador no windows
P: como recuperar uma aba fechada sem querer
P: abri e fechei a aba sem querer
R: Ctrl+Shift+T reabre a última aba fechada (funciona no Chrome, no Edge e no Firefox).

P: como abrir uma nova aba no navegador
P: como fechar a aba do navegador pelo teclado
R: Ctrl+T abre uma nova aba e Ctrl+W fecha a aba atual.

P: como abrir uma janela anônima no navegador
P: como navegar em modo privado
R: Ctrl+Shift+N no Chrome e no Edge; Ctrl+Shift+P no Firefox.

P: como aumentar o zoom da tela
P: como diminuir o zoom
P: as letras estão muito pequenas
R: Ctrl e + aumenta o zoom, Ctrl e - diminui, Ctrl+0 volta ao normal. Win e + abre a Lupa do Windows.

P: como fechar o programa ou a janela pelo teclado
P: o que faz alt f4
R: Alt+F4 fecha a janela ativa. Na área de trabalho, abre a opção de desligar.

P: como abrir o menu iniciar pelo teclado
P: como pesquisar um programa no windows
R: Aperte a tecla Win e comece a digitar o nome do programa.

P: como abrir a central de notificações no windows
P: o que faz win n
R: Win+N no Windows 11 (Win+A no Windows 10) abre as notificações.

P: como abrir as configurações rápidas de wifi e som
P: o que faz win a
R: Win+A no Windows 11 abre as configurações rápidas: Wi-Fi, Bluetooth, volume e brilho.

P: como projetar a tela em outro monitor
P: como duplicar a tela no projetor
P: o que faz win p
R: Win+P escolhe o modo de projeção: duplicar, estender ou só a segunda tela.

P: como abrir o ditado por voz no windows
P: como digitar falando
R: Win+H abre a digitação por voz.

P: como gravar a tela no windows
P: como gravar um vídeo da tela
R: Win+Alt+R grava a janela do jogo ou programa (Xbox Game Bar). No Windows 11, a Ferramenta de Captura (Win+Shift+S) também grava vídeo.
