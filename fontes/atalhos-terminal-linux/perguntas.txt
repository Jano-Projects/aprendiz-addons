# Comandos do terminal Linux (bash).
# Várias linhas P: no mesmo bloco = jeitos diferentes de perguntar a mesma coisa.

P: como listar os arquivos de uma pasta no terminal linux
P: como ver o que tem na pasta
P: comando para listar arquivos
P: como ver os arquivos ocultos
P: o que faz o ls
R: `ls` lista os arquivos. `ls -la` mostra também os ocultos, com detalhes (permissões, tamanho, data).

P: como entrar em uma pasta no terminal linux
P: como mudar de pasta no terminal
P: como voltar uma pasta no terminal
P: o que faz o cd
R: `cd nome-da-pasta`. Para voltar uma pasta: `cd ..`. Para ir à pasta pessoal: `cd ~`. Para voltar à pasta anterior: `cd -`.

P: como saber em qual pasta eu estou no terminal linux
P: como ver o caminho da pasta atual
P: o que faz o pwd
R: `pwd` mostra o caminho da pasta atual.

P: como criar uma pasta no terminal linux
P: comando para criar diretório
P: o que faz o mkdir
R: `mkdir nome`. Para criar várias pastas encadeadas de uma vez: `mkdir -p a/b/c`.

P: como criar um arquivo vazio no terminal linux
P: o que faz o touch
R: `touch arquivo.txt` cria um arquivo vazio (ou atualiza a data de um que já existe).

P: como copiar um arquivo no terminal linux
P: comando para copiar arquivo
P: como copiar uma pasta inteira no terminal
P: o que faz o cp
R: `cp origem destino`. Para copiar uma pasta inteira: `cp -r pasta destino`.

P: como mover ou renomear um arquivo no terminal linux
P: como renomear um arquivo no terminal
P: como mudar o nome de uma pasta no terminal
P: o que faz o mv
R: `mv origem destino`. O mesmo comando serve para mover e para renomear.

P: como apagar um arquivo no terminal linux
P: como apagar uma pasta no terminal
P: comando para excluir arquivo
P: o que faz o rm
R: `rm arquivo`. Para apagar uma pasta e tudo dentro dela: `rm -r pasta`. Cuidado: não vai para a lixeira.

P: como ver o conteúdo de um arquivo de texto no terminal linux
P: como ler um arquivo no terminal
P: o que faz o cat
P: o que faz o less
R: `cat arquivo` mostra tudo de uma vez. Para arquivos longos, `less arquivo` permite rolar; aperte `q` para sair.

P: como ver o começo ou o fim de um arquivo no terminal linux
P: como acompanhar um log no terminal
P: o que faz o tail
R: `head arquivo` mostra as primeiras linhas e `tail arquivo` as últimas. `tail -f arquivo` acompanha o arquivo enquanto ele cresce (bom para logs).

P: como editar um arquivo de texto no terminal linux
P: como usar o nano
P: como salvar e sair do nano
R: `nano arquivo` abre o editor. Ctrl+O salva, Ctrl+X sai.

P: como sair do vim
P: estou preso no vim
R: Aperte Esc, digite `:q` e Enter para sair. `:wq` salva e sai; `:q!` sai sem salvar.

P: como procurar um texto dentro de arquivos no terminal linux
P: como pesquisar uma palavra nos arquivos
P: o que faz o grep
R: `grep -r "texto" pasta` procura o texto em todos os arquivos da pasta. Use `-i` para ignorar maiúsculas.

P: como procurar um arquivo pelo nome no terminal linux
P: como achar um arquivo no linux
P: o que faz o find
R: `find . -name "*.txt"` procura, a partir da pasta atual, arquivos terminados em .txt.

P: como ver o espaço livre no disco no terminal linux
P: como saber se o disco está cheio
P: como ver o tamanho de uma pasta
P: o que faz o df
R: `df -h` mostra o espaço de cada disco. Para o tamanho de uma pasta: `du -sh pasta`.

P: como ver o uso de memória no terminal linux
P: quanto de memória ram está livre
P: o que faz o free
R: `free -h` mostra a memória total, usada e livre.

P: como ver os programas em execução no terminal linux
P: como fechar um programa travado no linux
P: como matar um processo
P: o que faz o top
R: `top` (ou `htop`, se estiver instalado) mostra os processos em tempo real; aperte `q` para sair. Para encerrar um processo: `kill número-do-processo`, ou `pkill nome`.

P: como dar permissão de execução a um arquivo no terminal linux
P: como tornar um script executável
P: permissão negada ao rodar script
P: o que faz o chmod
R: `chmod +x arquivo`. Depois ele pode ser executado com `./arquivo`.

P: como executar um comando como administrador no linux
P: o que faz o sudo
P: como virar root
R: `sudo comando` executa como administrador (pede a sua senha). Se o seu usuário não está no grupo sudo, use `su -` com a senha do root.

P: como atualizar o sistema no Debian ou Ubuntu
P: como atualizar o ubuntu pelo terminal
P: o que faz apt upgrade
R: `sudo apt update && sudo apt upgrade`.

P: como instalar um programa no Debian ou Ubuntu
P: como instalar pacote com apt
R: `sudo apt install nome-do-pacote`. Para procurar: `apt search nome`.

P: como atualizar o sistema no Fedora
P: o que faz dnf upgrade
R: `sudo dnf upgrade`.

P: como instalar um programa no Fedora
P: como instalar pacote com dnf
R: `sudo dnf install nome-do-pacote`. Para procurar: `dnf search nome`.

P: como descompactar um arquivo zip no terminal linux
P: como extrair um tar gz
P: como abrir um arquivo compactado no terminal
R: `unzip arquivo.zip`. Para arquivos .tar.gz: `tar -xzf arquivo.tar.gz`.

P: como compactar uma pasta no terminal linux
P: como criar um arquivo zip no terminal
R: `zip -r arquivo.zip pasta` ou, em .tar.gz, `tar -czf arquivo.tar.gz pasta`.

P: como baixar um arquivo da internet pelo terminal
P: o que faz o wget
P: o que faz o curl
R: `wget endereço` ou `curl -O endereço` baixa o arquivo para a pasta atual.

P: como ver o endereço IP do computador no terminal linux
P: qual o meu ip no linux
P: o que faz ip a
R: `ip address` (ou só `ip a`) mostra os endereços de cada placa de rede.

P: como testar se a internet está funcionando no terminal
P: o que faz o ping
R: `ping -c 4 8.8.8.8` envia 4 pacotes e mostra se houve resposta.

P: como cancelar um comando que está rodando no terminal linux
P: como parar um comando travado no terminal
R: Aperte Ctrl+C.

P: como limpar a tela do terminal linux
P: o que faz o clear
R: `clear`, ou o atalho Ctrl+L.

P: como buscar um comando que eu já digitei no terminal linux
P: como ver o histórico de comandos
P: o que faz o history
R: Aperte Ctrl+R e comece a digitar parte do comando. `history` mostra a lista completa.

P: como copiar e colar no terminal linux
P: ctrl c não copia no terminal
R: Ctrl+Shift+C copia e Ctrl+Shift+V cola (no terminal, Ctrl+C cancela o comando).

P: como ver a ajuda de um comando no terminal
P: como saber o que um comando faz
P: o que faz o man
R: `man comando` abre o manual (aperte `q` para sair). Muitos comandos também aceitam `comando --help`.

P: como desligar ou reiniciar o computador pelo terminal
P: comando para reiniciar o linux
R: `systemctl poweroff` desliga e `systemctl reboot` reinicia.
